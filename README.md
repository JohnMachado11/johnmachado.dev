# johnmachado.dev

Personal website of John Machado.

**Live site:** https://johnmachado.dev

Built with plain HTML, CSS, and JavaScript: no framework and no build step. Responsive across phones, tablets, and desktops; accessible (keyboard navigation, WCAG AA contrast, reduced-motion support); and fast (about 1.6 MB with every image loaded). The contact form is delivered through Web3Forms, and the site is hosted on GitHub Pages.

## Run locally

    python3 -m http.server 8000

Then open http://localhost:8000.
